CILIUM

Here's the full Cilium BGP auto-discovery setup we use in production. First, make sure your cluster supports BGP peering (most bare-metal and on-prem setups do, cloud providers vary). Install Cilium with BGP control plane enabled using Helm. Then create a CiliumBGPPeeringPolicy resource that defines your AS number and which node labels should participate in peering — Cilium will auto-discover available BGP routers from there and establish sessions without manual IP configs. The biggest gotcha we hit: make sure your firewall rules allow TCP port 179 (BGP) between nodes and routers, or peering silently fails. Also, if you're using MetalLB already, you'll need to migrate — running both causes IP announcement conflicts. Once it's live, check peering status with 'cilium bgp peers' command. LoadBalancer Service IPs get announced automatically within seconds of creation. We went from 2-hour network change windows to zero human intervention.
