SETUP

Here's the full MCP + Kubernetes setup: 1. Install the MCP server: pip install mcp-server-kubernetes 2. Make sure your kubeconfig is set (usually at ~/.kube/config). The MCP server uses the same auth as kubectl. 3. Run the server: mcp-k8s-server --kubeconfig ~/.kube/config 4. In Claude Desktop (or your AI tool), add the MCP server to your config file (usually ~/Library/Application Support/Claude/claude_desktop_config.json on Mac). Add this block: { 'mcpServers': { 'kubernetes': { 'command': 'mcp-k8s-server', 'args': ['--kubeconfig', '/path/to/.kube/config'] } } } 5. Restart Claude. Now you can ask it things like 'List all pods in the default namespace' or 'Why is my nginx deployment failing?' and it'll query your cluster in real time. Pro tip: Start with read-only questions (get pods, describe, logs). MCP can also modify resources, but test carefully in a dev cluster first. Let me know if you hit any issues!
