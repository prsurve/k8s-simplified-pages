LFX

LFX Mentorship runs three terms per year: Spring (Mar-May), Summer (Jun-Aug), and Fall (Sep-Nov). Applications typically open 4-6 weeks before each term starts. Here's how to pick a project: Look for ones that list 'good first issue' or 'beginner friendly' but still involve real K8s components like controllers, operators, or schedulers. Avoid documentation-only projects if you want technical depth. Read the project's last term report on GitHub to see what previous mentees actually built. In your application, show you've actually run the project locally and understood one small piece of the codebase — mention a specific file or function. Maintainers want curiosity and persistence over expertise. The stipend is around $3000-6600 depending on the term length. You'll work 20-40 hrs/week. Check mentorship.lfx.linuxfoundation.org for the current term's project list and deadlines. Apply to 2-3 projects you're genuinely interested in, not just the easiest ones. The selection rate is around 10-15%, so your proposal matters — be specific about what you want to learn and build.
