GATHER

Here's the full breakdown on OpenShift Virtualization must-gather. The default cluster must-gather (oc adm must-gather) grabs generic cluster state — pod logs, events, resource configs — but it does NOT collect anything VM-specific. For a VM incident you need the dedicated image: oc adm must-gather --image=registry.redhat.io/container-native-virtualization/cnv-must-gather-rhel8:v4.14 (swap the version tag to match your OpenShift Virtualization release). This pulls: 1) VirtualMachine and VirtualMachineInstance specs and status across namespaces, 2) libvirt domain XML and logs from the virt-launcher pods (this is where you actually see why a VM crashed at the hypervisor level), 3) CDI (Containerized Data Importer) status for any disk/import issues, 4) virt-handler and virt-controller logs from the CNV operator namespace, 5) network attachment and storage class info relevant to the VM. It all lands in a timestamped local folder you can tar up and attach directly to a Red Hat support case — no back and forth explaining what happened. Rule of thumb: run it the moment you see a VM in CrashLoop, stuck Migrating, or failing to start, before you touch anything else. It preserves state that gets overwritten fast once you start restarting things.
