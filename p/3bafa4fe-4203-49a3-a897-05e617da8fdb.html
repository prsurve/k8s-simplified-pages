ROADMAP

Here's the full v1.37 breakdown for beginners: 1. Job API stable: Batch workloads (data processing, ML training) are now prod-grade. No more beta warnings. 2. Pod Topology Spread matchLabelKeys: Spread pods across zones without complex affinity. Way cleaner YAML. 3. VolumeAttributesClass (beta): Change storage IOPS/throughput on the fly. Huge for databases that need performance tuning without downtime. 4. Kubectl describe improvements: Pending pods now show specific blockers (resources/taints/affinity). Saves 20 minutes of guessing. 5. Contextual logging (stable): Controller logs now include context about what triggered the action. Debugging reconciliation loops just got 10x easier. 6. Security: PodSecurityPolicy is fully removed (deprecated in 1.21). If you're still using it, migrate to Pod Security Standards NOW. 7. Alpha features to watch: Job success/failure policies, native sidecar containers (finally!), and sleep action in lifecycle hooks. Upgrade path: Test in dev with 1.37, but wait until 1.39 or 1.40 for prod. Let the community find the edge cases first. The Job API and logging features alone are worth planning your upgrade roadmap around.
