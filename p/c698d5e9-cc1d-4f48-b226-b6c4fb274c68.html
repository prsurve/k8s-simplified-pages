TRACE

Here's a minimal OpenTelemetry sidecar setup for tracing AI agents in Kubernetes. This injects an OTel collector as a sidecar, exports traces to Jaeger, and tags spans with agent metadata. First, deploy Jaeger in your cluster (helm install jaeger jaegertracing/jaeger --set allInOne.enabled=true). Then add this to your agent deployment YAML: a sidecar container running otel/opentelemetry-collector-contrib with a config that receives OTLP traces on port 4317 and exports to Jaeger. In your agent code, instrument with the OpenTelemetry SDK (Python: opentelemetry-api + opentelemetry-sdk), create a tracer, and wrap each tool call in a span. Tag spans with attributes like agent.id, tool.name, prompt.tokens, completion.tokens, and tool.latency_ms. Set OTEL_EXPORTER_OTLP_ENDPOINT to http://localhost:4317 so your app sends traces to the sidecar. The sidecar forwards to Jaeger. Query Jaeger UI by agent ID or tool name to debug failures.
