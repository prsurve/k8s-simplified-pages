What's your biggest K8s + GPU question? — @k8s.simplified · Kubernetes, explained like you're not a robot "DGX Spark is just a fancy server. Here's what actually matters for running AI agents on it. First, DGX Spark has 8 GPUs. Kubernetes doesn't see GPUs by default. You need the NVIDIA device plugin. Install it once. Now your pods can request GPUs just like CPU or memory. One line in your YAML. Next: your AI agent needs libraries. Don't install them in the pod. Bake them into a Docker image with CUDA pre-installed. Deploy it as a Deployment, not a Job. AI agents are long-running services, not batch tasks. Use a LoadBalancer or Ingress. Most beginners over-complicate this. DGX is just hardware. K8s schedules the pods. The GPU plugin connects them. That's it. One mistake I made: not setting GPU limits. One pod ate all 8 GPUs. Set limits, always. Save this for when you need it."
