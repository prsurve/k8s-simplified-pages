LLMSTACK

Here's the full LLM-on-K8s stack breakdown: 1. GPU Node Pool: Use GKE with n1-standard-4 + NVIDIA T4 (inference) or A100 (training). On EKS, use p3.2xlarge or g4dn.xlarge instances. Enable GPU in your node pool config. 2. NVIDIA Device Plugin: kubectl create -f https://raw.githubusercontent.com/NVIDIA/k8s-device-plugin/v0.14.0/nvidia-device-plugin.yml — this DaemonSet exposes GPUs as a schedulable resource. 3. Deployment YAML: Your container spec needs resources.limits with nvidia.com/gpu: 1. Also set tolerations if your GPU nodes are tainted. Mount model weights from S3 using an init container or CSI driver like s3-csi. 4. Model Server: Use vLLM (faster, better batching) or Hugging Face TGI. Both are production-ready. Run them as a Deployment with replicas=1 per GPU (LLMs don't share GPUs well). 5. HPA: Scale on custom metrics like queue depth from SQS/RabbitMQ using KEDA, not CPU. LLM inference pegs CPU at 100% even when idle because of batching. 6. Storage: Store model weights in S3. Use an init container to download them into an emptyDir volume at pod startup. A 7B model is roughly 14GB in float16. Never bake it into your image — build times and registry costs will destroy you. Cost estimate: T4 node on GKE = roughly $0.35/hour + $0.10/hour for the node itself. For 24/7 inference, expect $300-350/month per replica. Use spot instances to cut this by 60-70% if you can handle interruptions. Let me know if you hit any issues — I've debugged this stack a dozen times now.
