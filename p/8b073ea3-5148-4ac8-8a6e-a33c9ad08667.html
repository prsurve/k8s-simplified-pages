Here's your LitmusChaos beginner setup: 1. Spin up a test K8s cluster (Minikube or Kind works fine) 2. Install Litmus: kubectl apply -f https://litmuschaos.github.io/litmus/litmus-operator-v3.yaml 3. Wait for pods to be ready: kubectl get pods -n litmus 4. Access ChaosCenter UI: kubectl port-forward svc/chaos-litmus-frontend-service 9091:9091 -n litmus 5. Open localhost:9091, create a project, and run the 'pod-delete' experiment on a sample nginx deployment Start with pod-delete — it's the simplest way to see K8s self-healing in action. Watch your ReplicaSet spin up a new pod automatically. That's when it clicks. Once you're comfortable, try node-cpu-hog or pod-network-latency experiments.
