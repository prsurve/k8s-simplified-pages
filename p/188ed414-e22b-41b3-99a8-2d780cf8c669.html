CLUSTERAPI

Here's how to set up the Cluster API plugin for Headlamp: 1. Install Headlamp (if you haven't): helm repo add headlamp https://headlamp-k8s.github.io/headlamp/ && helm install headlamp headlamp/headlamp 2. Enable the Cluster API plugin: helm upgrade headlamp headlamp/headlamp --set plugins.clusterapi.enabled=true 3. Make sure your management cluster has Cluster API installed (clusterctl init if you're starting fresh). 4. Access Headlamp (usually port-forward or Ingress), navigate to the Cluster API section in the sidebar, and you'll see all your workload clusters listed with their health, node count, and control plane status. 5. Click into any cluster to see Machines, MachineDeployments, and scaling controls. This works best if you already have a few Cluster API-managed clusters running. If you're just learning Cluster API, spin up a management cluster with clusterctl and create a sample workload cluster using a provider like Docker (CAPD) or AWS (CAPA). The plugin will immediately show you how the CRDs map to real infrastructure. Let me know if you hit any snags!
