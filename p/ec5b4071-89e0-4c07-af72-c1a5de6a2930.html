The error? Two spaces. Here are the three dumbest YAML mistakes that will cost you an hour — and I've made all of them. Number one: mixing tabs and spaces. YAML only accepts spaces. If you copy-paste from Stack Overflow, those tabs will break everything silently. Number two: wrong indentation under containers. YAML

Here's my full YAML validation checklist I run before every apply: 1. yamllint your file locally (install via pip install yamllint) 2. kubectl apply --dry-run=client -f file.yaml (catches schema errors) 3. Use kubectl diff before applying to prod (shows exactly what will change) 4. Check indentation with cat -A (shows tabs as ^I) 5. Always quote strings that look like booleans: yes, no, true, false, on, off 6. Validate multi-doc YAMLs with --- separators carefully 7. Use a linter plugin in your editor (YAML extension for VSCode catches 80% before you even save) The dry-run flag alone has saved me countless times. It runs validation without actually creating resources. Combine it with --server-side to catch RBAC and admission controller issues too.
